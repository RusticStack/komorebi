# Environment variables and development switches


| Variable | Effect |
|---|---|
| `KOMOREBI_LANG=system`, `en` or `pt-PT` | The display language for this run, over the one saved in Settings (nothing is saved). |
| `KOMOREBI_DB=path` | Use this cache file instead of `%LOCALAPPDATA%\komorebi\cache.sqlite3` (`crash.log` and the diagnostics log's `logs` folder then go beside it too, draft attachments into `<path without extension>.drafts` and opened attachments into `<path without extension>.open`; each cache file has its own single-instance lock) |
| `KOMOREBI_PASSWORD=secret` | With `KOMOREBI_DB`, use this password instead of Credential Manager (debug builds, or release built with `--features dev-env-password`) |
| `KOMOREBI_FLOW=dir` | Debug builds only: script a full walk through the app (open, flag, read/unread, reply, a formatted message with an attachment whose draft must be saved and whose HTML part must arrive, move to Junk and back) on `[komorebi-test]` messages only, saving a log and snapshots to `dir` |
| `KOMOREBI_NO_SERVER_DRAFTS=1` | Debug builds only: keep drafts on this PC instead of copying them to the server's Drafts folder (used with `KOMOREBI_FLOW`, so a live test adds and removes no server messages) |
| `KOMOREBI_OFFLINE=1` | No network and no credential access (demo caches, timing runs) |
| `KOMOREBI_TIMING=1` | Print startup timings to stderr (up to the first frame drawn), and how long each opened message took to its first tile |
| `KOMOREBI_ACCENT=#rrggbb` | Use this accent colour instead of Windows' (an approximate ramp of shades around it), or 7 comma-separated colours, Dark3 to Light3, for an exact ramp (green: `#0c1c14,#173525,#1e4732,#26593f,#2e6a4b,#357c58,#40956a`; WinUI's blue: `#002642,#004275,#005a9e,#0078d7,#429ce3,#76b9ed,#a6d8ff`) |
| `KOMOREBI_THEME=contrast` | Show a contrast theme (any run, not only snapshots; `light` and `dark` are snapshot options, below): `KOMOREBI_CONTRAST=hc1`, `hc2`, `hcblack` (the default) or `hcwhite` (the four themes in `C:\Windows\Resources\Ease of Access Themes`), or 8 comma-separated colours: Window, WindowText, Highlight, HighlightText, Hotlight, GrayText, ButtonFace, ButtonText. hc1 `#2d3236,#ffffff,#a1bfde,#212d3b,#70ebde,#a6a6a6,#2d3236,#b6f6f0`; hc2 `#000000,#ffffff,#d6b4fd,#2b2b2b,#8080ff,#a6a6a6,#000000,#ffee32`; hcblack `#202020,#ffffff,#8ee3f0,#263b50,#75e9fc,#a6a6a6,#202020,#ffffff`; hcwhite `#fffaef,#3d3d3d,#903909,#fff5e3,#1c5e75,#676767,#fffaef,#202020` |
| `KOMOREBI_TEXT_SCALE=1.5` | Use this text size (1.0 to 2.25) instead of Windows' |
| `KOMOREBI_ANIMATE=0` | Act as if Windows' animation effects were off |
| `KOMOREBI_SYSTEM_TITLEBAR=1` | Keep the Windows title bar (with the search strip under it), as on Windows 10 and under high contrast |
| `KOMOREBI_TITLEBAR_BORDER=1` | Draw a 1 px line along the top of the app-drawn title bar, for a Windows that draws no top border over it |
| `KOMOREBI_SNAPSHOT=file.bmp` | Render the window to a file and exit (always at the default place and size; the saved window place is ignored). Options: `KOMOREBI_SIZE=WxH`, `KOMOREBI_THEME=light` or `dark` (over the theme chosen in Settings), `KOMOREBI_SNAPSHOT_SELECT=n` (or `a-b`: open message a, then Shift+Down to b, showing the "N selected" panel), `KOMOREBI_SNAPSHOT_WALK=n` (then open the next n messages, 250 ms apart), `KOMOREBI_SNAPSHOT_SCROLL=px` (scroll the reader), `KOMOREBI_SNAPSHOT_ACTION=reply`, `compose`, `compose-invalid` (a new message with a wrong To address, then Send: the error under To, which has the focus; nothing is sent), `compose-recipients` (a new message with recipients as chips in To and Cc, one wrong, an address being typed into To), `compose-no-to` (a new message with no recipient, then Send: "Add a recipient to send." under To), `compose-rich` (a new formatted message: bold, italic, underline, a colour, a link, both lists and a quote; `compose-rich-compact` is the same, for a narrow `KOMOREBI_SIZE`), `compose-table` (the same with a 3 x 3 table), `compose-format` (the same, and the link field open with an address typed), `compose-preview` (the same with Preview on: the HTML part drawn in the body's place), `compose-plain` (the same switched to plain text) and `compose-plain-ask` (the question before that), `compose-signature`, `settings-signatures` and `signature-edit` (only with `KOMOREBI_OFFLINE=1` on a throwaway cache, as they write two made-up signatures to it, one with a logo and set as the first account's defaults: a formatted message with it, Settings > Signatures, and the first signature's page), `drop-hover` and `drop-hover-compose` (a file dragged over the window with no composer or with one open: "Drop to attach to a new message" / "Drop to attach"), `draft-reply` (a reply to the selected message with a line typed, then Close: the reader's "You started a reply to this message." bar with Resume; offline only, as the draft is saved in the throwaway cache), `compose-suggest` (a new message with `al` typed into To: the recipient suggestions), `compose-attach` (a new message with three made-up attachments, the counter at 85%), `composer-window` (a formatted message moved to a composer window of its own, as Ctrl+O does; the snapshot is of that window, at the main window's size) and `composer-window:main` (the same; the snapshot is of the main window, its reading pane's "This message is open in its own window"), `drafts` (the Drafts view), `discard` (the newest saved draft, or on a cache with none a made-up message typed into a new one, then the Discard prompt), `guard` (the newest saved draft, then Send: the send guards' bar), `menu:list`, `menu:pane` or `menu:rail` (print the entries of the list's "..." menu, of the folder pane's row menu on All inboxes, each account line and the first folder shown of each account, or of each rail tile's menu, with their enabled state, to stderr and exit; no native menu is opened, which in a snapshot run would wait for a click), `menu:row`, `menu:more` or `menu:move` (the same for the row menu on what is selected, the reader's More menu, each item with its accelerator text and check mark, or the Move list: recent folders first, then the tree by depth), `select-mode` ("Select messages" on: the rows' check boxes), `move` (the Move list on what is selected, its filter focused), `delete-confirm` (the Trash question on what is selected; nothing is deleted), `not-downloaded` (the open message as if not downloaded with its server out of reach, in memory only: after 2 s the sentence and Retry; the snapshot waits for them), `outbox` (the Outbox view with its newest message), `outbox:permanent` or `outbox:transient` (only with `KOMOREBI_OFFLINE=1`, on a throwaway cache, as it writes it: a made-up message whose send failed, with a 550 5.1.1 "user unknown" reply (Edit leads) or a 421 "try again later" (Retry leads), opened in the Outbox with its sentence, Details and first lines; nothing is sent), `pane` (the narrow window's folder pane, opened over the content: use a width below 1040), `nav:collapsed` (the folder pane folded to the rail, as Ctrl+Shift+E does; at 1040 px or wider, and saved in the cache's settings, so use a throwaway copy), `tabs` or `tabs:n` (the list's first n messages, 3 by default, in tabs of their own, the first one shown: the tab strip and a message at full width), `windows:n` (the list's first n messages in message windows of their own; the snapshot is of the main window, for measuring memory with `examples/peak_memory`), `calendar` (the Calendar page) and `calendar:sample` (only with `KOMOREBI_OFFLINE=1`, on a throwaway cache, as it writes made-up events to its local calendar: the agenda with today's, tomorrow's, an all-day, a repeating and a cancelled event), `calendar:calendars` (the same, offline on a throwaway cache with an account, then the Calendars pane with two made-up CalDAV calendars, one turned off; nothing is looked up), `settings-rules` and `rule-edit` (only with `KOMOREBI_OFFLINE=1` on a throwaway cache, as they write three made-up rules for the first account: Settings > Rules, and the second rule's page), `settings`, `settings:signatures`, `settings:rules`, `settings:general`, `settings:privacy`, `settings:about` (or `settings:accounts`: Settings on that section), `update:checking`, `update:uptodate`, `update:available`, `update:downloading`, `update:failed`, `update:failed-verify` (Settings > About > Updates in a made-up state; nothing is looked up or downloaded) and `update:banner` (the "Version X is available" bar over the list), `settings-edit` (Settings with the first account's edit form), `settings-edit-logins` (the same, with made-up IMAP and SMTP usernames), `settings-edit-folders` (the same, scrolled to its Folders: the roles Sent, Drafts, Trash, Archive and Junk, each header above its box), `menu:account` (prints the account page's "…" menu: Move up / Move down, with two accounts or more), `notice-why` (the sender notice's "Why?" dialog over the selected message), `remote-always-bar` (Always load from this sender on the selected HTML message, staying in the reader: the bar with Undo and Privacy settings), `cert-changed` (the first account's status line as when its saved certificate changed: the short sentence and Review certificate; made-up, nothing is sent), `cert-changed-settings` (the same, then Settings with that account's line), the onboarding flow (made up, nothing is looked up, checked or sent): `ob-email`, `ob-email-error` (a wrong address, its error under the field), `ob-finding` (Sign in while the lookup runs), `ob-found-preset` (a Purelymail address: settings built in), `ob-found` (a lookup's answer from a provider's autoconfig), `ob-notfound` (nothing found: the provider choice), `ob-password`, `ob-wait` and `ob-wait-slow` (the check's three stages, then the 10 s sentence), `ob-error-rejected`, `ob-error-unreachable`, `ob-error-cert` (one title, one sentence, one next step; "Show details" folded), `ob-manual` (the server settings), and, only with `KOMOREBI_OFFLINE=1` on a throwaway cache as they add a made-up account to it, `ob-personalise`, `ob-done` and `ob-done-progress` (Make it yours, the finish, and the finish at 1,234 of 5,000); `ob-embedded` opens the flow from Settings > Add account (a cache with an account). The rings show after a second, so add `KOMOREBI_SNAPSHOT_HOVER` to take the snapshot later. `settings-add`, `signin-wait`, `account-test-failed` and `account-find*` are kept as aliases of `ob-email`, `ob-wait`, `ob-error-rejected` and `ob-found` / `ob-notfound` / `ob-manual`, `fresh-inbox` (only with `KOMOREBI_OFFLINE=1`, on a throwaway cache, as it writes it: a made-up account added to the cache as just added, its Inbox in its first download at 1,234 of 5,000 and the list's progress; use an empty cache to see it alone), `account-cert-failed` (the first account's edit form after the secure connection failed on an untrusted certificate of a made-up server: the sentence and Review certificate), `account-cert-prompt` (the same with the Trust this certificate? prompt open: the whole SHA-256 fingerprint and the certificate's details; nothing is saved), `account-cert-again` (the prompt as when a forgotten certificate is reviewed again: the old fingerprint is shown too), `account-cert-pinned` (the edit form with a certificate saved for each server: the lines and Forget certificate), `remove-data` (Settings → Privacy with the Remove all data prompt; nothing is removed until it is confirmed), `plain` (plain-text view), `original` (Show original colours, in the dark theme), `source` (Show original on the selected message), `rsvp` (Accept on the selected invitation: the reply prompt; nothing is sent until it is confirmed), `select-all` (select and copy the page), `scroll-right` (scroll a page wider than the reader to its right edge), `archive` (archive what is selected: the Undo offer; the move is held, so the cache is not changed), `undo-send` (a reply to the selected message, sent: the undo-send offer; only with `KOMOREBI_OFFLINE=1`, as the reply stays queued in the cache and the next start sends it, so use a throwaway copy), `junk` (Report junk on what is selected: on the seeded cache, which has no Junk folder, the line saying so), `offline` (the first account's status line as when its server can't be reached, with Try now, and the caution badge on its pane row and rail tile), `offline-settings` (the same, then Settings with that account's line), `settings-download` (Settings with the first account's mail downloading, made-up numbers; its bar shows after a second, so add `KOMOREBI_SNAPSHOT_HOVER` to take the snapshot later), `unread` (the Unread filter), `read-all` (Mark all as read, then the Unread filter: its empty state; this changes the cache, so use a copy), `tips` (the teaching tips of this layout from the first one), `tips:folders`, `tips:search` or `tips:help` (the series at that tip, its place counted as in the series: `tips:search` is "1 of 2" at 1280 and "2 of 3" at 900; `tips:folders` at 1040 px or wider prints "tip not applicable at this width" to stderr and exits 0 without a snapshot; nothing is saved as seen), `whats-new` (the What's new bar, on a cache with an account and no or another `whats_new_version`; otherwise it says so on stderr) or `shortcuts` (the Keyboard shortcuts dialog). Snapshot runs never start the tips or the What's new bar by themselves. `KOMOREBI_SNAPSHOT_SEARCH=text` types `text` into the search box first (with `KOMOREBI_SNAPSHOT_ACTION=search-all`, in the "All folders" scope; `joao` on the seeded cache). `KOMOREBI_SNAPSHOT_ACTION=menu:scope` prints the search scope menu, `inactive` draws the window as inactive (the title bar dims). `KOMOREBI_SNAPSHOT_TITLEBAR=custom` or `system` picks the title bar (snapshots draw the app's own unless `KOMOREBI_THEME=contrast`); every snapshot prints the bar's drawn and pushed height and its passthrough rectangles to stderr (`[titlebar]`), and the layout in effect (`[layout] width=… mode=wide|compact|one-pane list=… reader=…`; `KOMOREBI_SIZE=560x700` shows one pane). `KOMOREBI_SNAPSHOT_FOCUS` then moves the keyboard focus with real key presses from the list: `toolbar` (Tab: the reader's first button; `toolbar:n` then Right n times), `nav` (Shift+F6 to the folders; `nav:n` then Down n times; `nav:n:keys` then presses `l` Left, `r` Right, `u` Up, `d` Down or `e` Enter for each letter), `list` (the list's current row), `tab:n` (n Tabs) or `press:keys` (the letters above plus `n` PageDown, `p` PageUp, `h` Home, `z` End, `f` F6 and `t` Tab, pressed where the focus already is, such as a dialog's or a Settings page's: `press:ttt` walks three Tab stops into Settings, which `tab:n` would leave; in one pane with a message open the list is hidden, so `toolbar` and `tab:n`, which start from it, show no focus: use `press:t` there, or `press:de` to open a row from the list). `KOMOREBI_SNAPSHOT_HOVER=x,y` then points at x,y (logical px) to show a hover, `x,y:press` also holding the left button down there and `x,y:click` clicking there (the snapshot is taken 700 ms later, so a tooltip shows); `caption-min`, `caption-max` or `caption-close` (`:press` held down) show a caption button's state. `KOMOREBI_SNAPSHOT_CHECK=1` then exits with code 1 (and says which on stderr) if the message list or the reader came out blank (less than 1% of their pixels unlike the background); CI uses it with `KOMOREBI_SNAPSHOT_SELECT=0` |

Measurement tools against an account you authorize (credentials from an
env file with `EMAIL` and `PASSWORD_EMAIL`; output is numbers only):
`examples/probe` (read-only; `--send` mails the account itself once),
`examples/idle_check` (IDLE wake test), `examples/delivery_delay` and
`examples/modseq_check` (read-only), `examples/parse_cache` (runs every
cached body through the reader's parser).

`cargo run --release --example seed -- new.sqlite3 50000` fills a new cache
with a fake `.invalid` account and deterministic messages for timing runs
(open it with `KOMOREBI_OFFLINE=1` and `KOMOREBI_DB`). One sender has
accents ("João Gonçalves": an inbox message, two in Archive and one sent to
him), for checking the search. `KOMOREBI_TIMING=1` also prints how long
each search took.
`seed -- new.sqlite3 0 tests/fixtures/html` holds just the 14 synthetic HTML
messages, in file order (`KOMOREBI_SNAPSHOT_SELECT=n` opens file n+1), for
checking the reader; `tests/fixtures/notice` holds ten synthetic messages for
the sender notice, encrypted mail and Unsubscribe, and `tests/fixtures/invite` eight meeting invitations, and `tests/fixtures/reader` an emoji message and three heavy ones (a long newsletter, a 120-message digest, a 1,200-row statement) for timing the reader (see their READMEs). Add `--drafts` for two saved drafts (a new message and
a reply to the newest message), and `--outbox` for a message whose send failed
(in the Outbox) plus a newer draft with no subject that mentions an
attachment, and `--signature` for two named signatures set as the account's defaults. With an eml-dir,
`--html-reply` adds, newest, a reply to the newest HTML message as Komorebi
sends one (formatted text, signature and the sanitized HTML quote), as its
sender would receive it (`KOMOREBI_SNAPSHOT_SELECT=0` opens it). For the folder
pane, `--accounts` adds nested folders and two more `.invalid` accounts,
`--folders N` N more folders, and `--fold a2,f5` saves those lines folded (the
ids are printed). `examples/peak_memory` runs a program (the app, with
those variables set) and prints its peak working set and private memory.
